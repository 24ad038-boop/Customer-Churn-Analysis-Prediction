Customer Churn Analysis & Prediction is a mini machine learning project that analyzes customer behavior and predicts whether a customer is likely to churn or stay. The project uses Python, Pandas, Matplotlib, Seaborn, and Scikit-learn. Exploratory Data Analysis and visualizations are used to identify churn patterns based on factors such as tenure, monthly charges, contract type, and support calls. A Logistic Regression model is then used to predict customer churn and evaluate model performance using accuracy, confusion matrix, and classification report.

Technologies & Libraries:

Python
Jupyter Notebook
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn

Key Features:

Data collection and cleaning
Exploratory Data Analysis (EDA)
Customer churn visualization
Analysis of tenure, monthly charges, contract type, and support calls
Data preprocessing and label encoding
Logistic Regression for churn prediction
Accuracy evaluation
Confusion Matrix
Classification Report

Dataset: 200 customer records
Algorithm: Logistic Regression
Output: Predicts whether a customer is likely to Churn or Stay.
